# Neon / Arena

Prosta bijatyka 2D w przeglądarce, bez zewnętrznych zależności. Wybierz jedną z trzech postaci i pokonaj komputer w dwóch rundach.

Uruchom z katalogu repozytorium:

```sh
python3 -m http.server 8000
```

Otwórz stronę serwera w przeglądarce lub otwórz bezpośrednio `index.html`.

Sterowanie: A/D — ruch, W — skok, S — kucanie, J — cios, K — blok. Dostępne są także przyciski dotykowe. Postać obraca się do przeciwnika automatycznie. Cios niski wymaga niskiego bloku; stojący i powietrzny — wysokiego. Postaci różnią się siłą, szybkością i zasięgiem.
